Privacy Policy

Last updated: November 16, 2026

Purpose

CSR Nexus Backups is a private administrative utility used to back up the Coruscant Security Regiment Discord bot's database to Google Drive.

Information Processed

Backup files may contain Discord user identifiers, event participation records, quota information, and bot configuration data.

Google Drive Access

The application uses Google Drive authorization to upload, retrieve, and manage backup files created by the application.

Data Security

Backup files are encrypted before being uploaded to Google Drive. Access is restricted to the authorized administrator.

Data Retention

The application is intended to retain the seven most recent daily database backups. Older backups are scheduled for deletion according to the configured retention policy.

Data Sharing

Backup data is not sold or shared with advertisers. Google Drive is used as the backup storage provider.

Access and Deletion

The administrator can retrieve or delete stored backups and revoke Google Drive access through Google Account security settings.
